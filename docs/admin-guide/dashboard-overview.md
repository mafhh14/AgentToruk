# Dashboard overview

The AgentToruk admin dashboard is your control center for AI customer support.

## Main sections

| Section | Purpose |
|---------|---------|
| **Dashboard** | KPIs — conversations, tickets, AI rate, CSAT |
| **Conversations** | All chat sessions, human takeover |
| **Tickets** | Support issues with status workflow |
| **Knowledge** | Upload and manage RAG documents |
| **Agent** | AI personality, model, escalation rules, widget theme |
| **Workflows** | Automation rules (billing → ticket, etc.) |
| **Analytics** | Trends, gaps, performance |
| **Team** | Invite members, assign roles |
| **Settings** | API keys, webhooks, embed code |

## Roles

| Role | Access |
|------|--------|
| Owner | Full access |
| Admin | Config, knowledge, team |
| Support Agent | Conversations, tickets |
| Viewer | Read-only analytics |
